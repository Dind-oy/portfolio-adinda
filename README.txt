PORTFOLIO ADINDA - PANDUAN SINGKAT

Isi folder:
- index.html : struktur dan isi website
- style.css  : warna, layout, ukuran, dan tampilan
- script.js  : interaksi menu mobile dan tahun otomatis

CARA MENJALANKAN:
1. Ekstrak file ZIP ini.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder.
4. Pilih folder "portfolio-adinda".
5. Buka file index.html.
6. Klik kanan pada area kode lalu pilih "Open with Live Server" jika ekstensi Live Server sudah dipasang.
   Alternatif: buka folder melalui File Explorer, lalu klik dua kali index.html untuk melihatnya di browser.

SEBELUM DIPUBLIKASIKAN:
- Ganti emailkamu@example.com dengan email aktif.
- Periksa kembali tahun pendidikan, nilai, dan seluruh deskripsi.
- Tambahkan foto sendiri jika ingin (tidak wajib).
- Tambahkan tautan GitHub hanya untuk proyek yang sudah diunggah dan aman dipublikasikan.
- Jangan masukkan password, API key, file .env, atau data pribadi ke repository publik.
